# Quantum Sand Bevy level editor

This Rust crate is used as a built-in game level editor.

You can edit the game levels inside the game itself.

Use custom React UI components; to modify and script game assets; with Quantum Sand Rails as the backend.

Use any scripting language you wish; such as; Python, Ruby, Rust, JavaScript, Elixir, Go.

The game levels are stored as JSON within PostgreSQL.
